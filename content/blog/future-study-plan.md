# 관심 있는 요소
또한 충북 정보보안 대회에 참여했을 때 공격도 중요하지만 방어 또한 중요하다는 것을 느꼈다. 이러한 경험을 통해 보안 관제에 관심을 가지게 되었다.

##### 보안 관제란?
보안 관제란 조직의 정보 자산을 보호하기 위해 네트워크와 시스템 전반에 걸쳐 발생하는 이상 징후를 탐지, 분석, 대응하는 일련의 활동이다

이러한 보안 관제 직무를 위해 필요한 역량은 다음과 같다

• 보안 이벤트와 로그 등 관제 데이터를 분석하는 역량
• ESM, IPS, WAF, DDoS 대응 장비 등 보안 도구에 대한 이해

# 학습 계획
보안 관제를 위한 역량을 키우기 위한 과정은 다음과 같다.

| 단계       | 배울 것                                      | 할 수 있어야 하는 것                           |
| -------- | ----------------------------------------- | -------------------------------------- |
| 1. IT 기초 | TCP/IP, DNS, HTTP, Linux·Windows, 웹 서버 구조 | 접속이 어떻게 이루어지고 로그가 어디에 남는지 설명           |
| 2. 분석 기초 | 방화벽·웹·시스템 로그, 패킷 분석, 정상 트래픽과 이상 징후        | 경고 하나를 보고 발생 시각, 출발지, 대상, 행위를 추적       |
| 3. 관제 실습 | SIEM 검색, ESM·IDS·IPS·WAF 경고 해석, 오탐 판별     | 경고의 근거를 확인하고 대응 필요 여부를 판단              |
| 4. 대응 훈련 | 사고 분류, 보고, 상위 담당자 전달, 인수인계                | “무슨 일이 있었고, 무엇을 확인했으며, 다음 조치는 무엇인지” 기록 |

##### 지금 해야할 공부

1. **네트워크를 쪼금 더 깊이 공부하기**
   네트워크의 TCP/IP나 DNS, HTTP등을 공부해서 네트워크 접속에 대해 더 공부하기
   
2. **웹 서버와 윈도우,리눅스 시스템 공부**
   로그가 어디에 어떻게 남는지 알아보고 가능하다면 로그를 분석하는 법도 공부하기

3. **분석 도구 공부**
   wireshark 등의 분석 도구를 더 깊이 공부하고 경고 신호를 공부하기

일단 이러한 공부를 한 후 이 이후에 관제 실습, 대응 훈련에 대한 공부를 할 계획이다.
